    def _draw_token(

        size: float,

        style = COLOR_STYLES[color]
        inset = size * 0.075
        x0, y0 = x + inset, y + inset
        x1, y1 = x + size - inset, y + size - inset
        radius = size * 0.13
        rounded_rect(canvas, x0, y0 + size * 0.035, x1, y1 + size * 0.03, radius, fill=style["edge"])

        center_x = x + size / 2
        center_y = y + size / 2
        if rank is None:
            draw_sabres(
                canvas, center_x, center_y, size * 0.42, style["mark"], max(2, size * 0.04)
            )
            return

        symbol_y = center_y - size * 0.11
        if rank is Rank.BOMB:
            self._draw_bomb(canvas, center_x, symbol_y, size)
        elif rank is Rank.FLAG:
            self._draw_flag(canvas, center_x, symbol_y, size)
        else:

Sie ist Teil der grafischen Oberfläche. Sie verändert nicht die Spiellogik, sondern erzeugt nur die visuelle Darstellung einer Figur: Farbe, Form, Rückseite oder Rangsymbol.

Gesamtbild der Methode
Vereinfacht gesagt macht _draw_token Folgendes:``` python
def _draw_token(...):
    # 1. Farben bestimmen
    # 2. Rechteck-Koordinaten berechnen
    # 3. Spielstein mit Schatten zeichnen
    # 4. Wenn verdeckt:
    #      Rückseiten-Symbol zeichnen und fertig
    # 5. Wenn sichtbar:
    #      Bombe/Fahne/Symbol/Zahl zeichnen
    #      Kurzname darunter schreiben
```

 
Warum ist rank: Optional[Rank] wichtig?
Der Typ:``` python
Optional[Rank]
```

bedeutet:``` python
Rank | None
```

Also: Der Wert kann entweder ein Rank sein oder None.
Das ist eine elegante Lösung für verdeckte Gegnerfiguren.
Statt eine extra Variable wie visible: bool zu übergeben, sagt die Methode:
rank is None → verdeckt zeichnen
rank vorhanden → offen zeichnen
Das ist kurz und gut lesbar.
 
Beispiel
Angenommen, eine rote Figur ist sichtbar und hat den Rang Rank.MINER.
Dann passiert ungefähr:
Roter Stil wird geladen.
Ein roter abgerundeter Spielstein mit dunkler Kante wird gezeichnet.
In der Mitte oben wird "3" gezeichnet.
Unten wird "Mineur" gezeichnet.
Bei einer verdeckten blauen Figur:
Blauer Stil wird geladen.
Ein blauer Spielstein wird gezeichnet.
In der Mitte werden gekreuzte Säbel gezeichnet.
Keine Ranginformationen werden angezeigt.
