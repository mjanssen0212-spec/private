Erkläre die folgende Methode:

    def _draw_token(
        self,
        canvas: "tk.Canvas",
        x: float,
        y: float,
        size: float,
        color: Color,
        rank: Optional[Rank],
    ) -> None:
        style = COLOR_STYLES[color]
        inset = size * 0.075
        x0, y0 = x + inset, y + inset
        x1, y1 = x + size - inset, y + size - inset
        radius = size * 0.13
        rounded_rect(canvas, x0, y0 + size * 0.035, x1, y1 + size * 0.03, radius, fill=style["edge"])
        rounded_rect(canvas, x0, y0, x1, y1 - size * 0.01, radius, fill=style["face"])

        center_x = x + size / 2
        center_y = y + size / 2
        if rank is None:
            draw_sabres(
                canvas, center_x, center_y, size * 0.42, style["mark"], max(2, size * 0.04)
            )
            return

        symbol_y = center_y - size * 0.11
        if rank is Rank.BOMB:
            self._draw_bomb(canvas, center_x, symbol_y, size)
        elif rank is Rank.FLAG:
            self._draw_flag(canvas, center_x, symbol_y, size)
        else:
            canvas.create_text(
                center_x, symbol_y,
                text="S" if rank is Rank.SPY else str(rank.strength),
                fill=TEXT, font=self._font(size * 0.37, True),
            )
        canvas.create_text(
            center_x, center_y + size * 0.24,
            text=rank.short, fill=TEXT, font=self._font(size * 0.15),
        )

_draw_token zeichnet einen einzelnen Spielstein auf ein Tkinter-Canvas. Dem Code nach gehört er zu einem Stratego-artigen Spiel, denn es gibt Bombe, Fahne, Spion und Stärkewerte. Die Methode zeichnet zuerst den Stein und danach entweder die verdeckte Rückseite oder die sichtbare Vorderseite.

Die Parameter
canvas: die Zeichenfläche. Die Anführungszeichen bei "tk.Canvas" machen den Typ zu einer Forward Reference. Er wird also nicht beim Laden des Moduls ausgewertet, sodass tk dann noch nicht importiert sein muss.
x, y: vermutlich die linke obere Ecke des Spielfelds.
size: die Seitenlänge des Felds.
color: die Spielerfarbe.
rank: der Rang des Steins. None bedeutet hier, dass der Stein verdeckt gezeichnet wird.
Schritt für Schritt
1. Stil und Maße bestimmen
python
style = COLOR_STYLES[color]
inset = size * 0.075
x0, y0 = x + inset, y + inset
x1, y1 = x + size - inset, y + size - inset
radius = size * 0.13
style enthält die Farben für diesen Spieler. inset ist der Abstand zum Feldrand, damit der Stein nicht das ganze Feld ausfüllt. Daraus ergeben sich die Ecken (x0, y0) und (x1, y1).

Alle Maße hängen von size ab. Dadurch skaliert der Stein automatisch mit, wenn sich die Feldgröße ändert.

2. Den Stein mit 3D-Effekt zeichnen
python
rounded_rect(canvas, x0, y0 + size * 0.035, x1, y1 + size * 0.03, radius, fill=style["edge"])
rounded_rect(canvas, x0, y0, x1, y1 - size * 0.01, radius, fill=style["face"])
Auf einem Canvas liegt alles, was später gezeichnet wird, über dem Früheren. Deshalb kommt zuerst die Kante und dann die Oberseite. Die Kante ist etwas nach unten versetzt, sodass unten ein schmaler Streifen sichtbar bleibt. So wirkt der Stein, als hätte er Dicke.

3. Mittelpunkt berechnen
python
center_x = x + size / 2
center_y = y + size / 2
Das ist der Bezugspunkt für alle folgenden Symbole und Texte.

4. Verdeckten Stein zeichnen
python
if rank is None:
    draw_sabres(
        canvas, center_x, center_y, size * 0.42, style["mark"], max(2, size * 0.04)
    )
    return
Bei einem verdeckten Stein werden nur Säbel gezeichnet. max(2, size * 0.04) sorgt für eine Linienstärke von mindestens 2, damit die Linien auch auf kleinen Feldern sichtbar bleiben.

Das return beendet die Methode sofort. Dieses Muster heißt Guard Clause oder Early Return und erspart einen else-Block mit zusätzlicher Einrückung.

5. Symbol oder Zahl zeichnen
python
symbol_y = center_y - size * 0.11
if rank is Rank.BOMB:
    self._draw_bomb(canvas, center_x, symbol_y, size)
elif rank is Rank.FLAG:
    self._draw_flag(canvas, center_x, symbol_y, size)
else:
    canvas.create_text(
        center_x, symbol_y,
        text="S" if rank is Rank.SPY else str(rank.strength),
        fill=TEXT, font=self._font(size * 0.37, True),
    )
Das Symbol sitzt etwas über der Mitte, damit unten Platz für den Namen bleibt. Es gibt drei Fälle:

Rang	Darstellung
Bombe	eigene Zeichnung mit _draw_bomb
Fahne	eigene Zeichnung mit _draw_flag
Spion	Buchstabe „S“
alle anderen	Stärkewert als Zahl
Enum-Werte vergleicht man üblicherweise wie hier mit is, weil jedes Enum-Mitglied nur einmal existiert. Das True in _font steht vermutlich für Fettdruck.

6. Kurznamen darunter schreiben
python
canvas.create_text(
    center_x, center_y + size * 0.24,
    text=rank.short, fill=TEXT, font=self._font(size * 0.15),
)
Dieser Text steht für alle sichtbaren Steine im unteren Bereich und ist kleiner als das Symbol. create_text zentriert Text standardmäßig um die angegebene Position, daher sitzt er genau in der Mitte des Steins.
